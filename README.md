# Auto Light Switch

## Download

[Download auto-light-switch.zip](https://merthsoft.com/RimWorld/auto-light-switch.zip) — RimWorld 1.7 release.

The archive includes older supported version folders where available. Extract the mod folder into RimWorld's `Mods` directory.

Automatically controls lights based on room occupancy. Optional workbench and medical-monitor power saving are disabled by default; configure them in Mod Settings.
